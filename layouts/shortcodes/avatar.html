{{/* Optimised author avatar. The homepage used to hardcode ``, which served the raw 1000x1128 JPEG (~271 KB) into a 170px circle and bypassed Hugo's image pipeline entirely. That single image was ~19% of homepage weight. This shortcode runs the source through the pipeline instead, emitting a resized copy plus a 2x variant for high-DPI screens. `.Fill` keeps the source format (JPEG here) and honours the site's `imaging.quality: 75` and Lanczos resampler, so 170x170 lands at ~4.5 KB (from 277 KB). Note: `.Fill` alone does not convert to WebP. To emit WebP, wrap with `.Process` and a `webp` target, e.g. {{ $1x = $img.Fill "170x170 Center" | images.Filter ... }} or set `imaging.defaultImageConfig` in the site config. Not done here to keep the change minimal; JPEG output is already ~98% smaller. Usage (inside any markdown block): {{< avatar >}} Optional named args: author - author folder under `content/authors/` (default "admin") size - CSS pixel size of the rendered square (default 170) emoji - status emoji anchored to the bottom-right (default "☕️") */}} {{- $author := .Get "author" | default "admin" -}} {{- $size := int (.Get "size" | default 170) -}} {{- $emoji := .Get "emoji" | default "☕️" -}} {{- $page := site.GetPage (printf "/authors/%s" $author) -}} {{- $img := "" -}} {{- with $page -}} {{- with (.Resources.ByType "image").GetMatch "avatar*" -}} {{- $img = . -}} {{- end -}} {{- end -}}
{{- if $img -}} {{- $1x := $img.Fill (printf "%dx%d Center" $size $size) -}} {{- $2x := $img.Fill (printf "%dx%d Center" (mul $size 2) (mul $size 2)) -}} {{- else -}} {{- warnf "avatar shortcode: no image resource found on /authors/%s" $author -}} {{- end -}}
{{- with $emoji -}} {{ . }} {{- end -}}
